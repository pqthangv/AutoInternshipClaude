Eligibility and preferences

Used for yes-or-no questions. If a question names a different country than yours, AutoInternship leaves it for you. Sponsorship questions about now or the future use the first sponsorship answer, and questions only about the internship use the second. A question that could mean either is filled only when both answers are the same.

Voluntary self-identification

Many U.S. applications end with these optional questions. AutoInternship answers one only with the choice you make here, and only when the form offers a matching option. Leave a question on “Not set” and AutoInternship leaves it for you. Some forms (Workday, for example) ask Hispanic or Latino and race in one list, so set both. Questions about pronouns, sexual orientation or transgender identity are always left for you.

Instructions for Claude

The internship-application skill reads these from your backup (profile.json) when it writes answers for you.

Fill button

Application pages get a small “Fill with AutoInternship” button on the right edge. You or Claude click it, and a panel lists what was filled and what’s left, so Claude only works on the rest. It never attaches your stored resume, because Claude attaches one tailored to each job (the popup and shortcut still do).

Only a real click starts a fill, so a web page can’t start one by itself.

Backup

The backup downloads as profile.json, the file the internship-application skill reads. Move it into your job-search folder (if your browser named it “profile (1).json”, rename it). Your resume file isn’t included.
